Privacy policy

Last updated 20 September 2026.

This policy covers the personal Google OAuth client used with rclone, an open source command line program, by the owner of this GitHub account.

Who uses this application

Only the owner of the application. It is not published, not distributed, and not offered to anyone else. There are no other users and no accounts are created.

What data is accessed

When authorised, the application uses the Google Drive API to read, create, update and delete files in the Google Drive account of the person who authorised it. That access is used solely to copy and synchronise files between that Google Drive account and a computer belonging to the same person.

How the data is handled

File contents and metadata pass directly between Google and the computer running rclone. They are not sent to any third party, not stored on any server operated by the owner of this application, and not used for advertising, analytics, profiling or machine learning.

The OAuth access token and refresh token are stored in the local rclone configuration file on that computer. They can be revoked at any time from the Google Account permissions page.

Data sharing and sale

No data obtained through Google APIs is shared with, transferred to, or sold to any third party.

Retention and deletion

No data is retained by this application beyond the local copies of the files being synchronised and the local credentials described above. Deleting the rclone configuration file removes the stored credentials. Revoking access in the Google Account settings ends all access immediately.

Limited use

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact
